# Орден Агентов

Живая ролевая игра (ЛАРП) для участников Claude Code Day.

Каждый игрок призывает персонажа: класс, происхождение, шесть характеристик, перк, проклятие и коронную фразу. Весь день он отыгрывает роль и выполняет квесты: половина делается в Claude Code (`/init`, охота на баг, режим планирования, хуки), половина в живом общении. За квесты начисляется опыт, ранги идут от Стажёра до Архитектора Ордена.

**Играть:** https://lawrensesqq.github.io/orden-agentov/

## Что внутри

- **Призыв персонажа.** Характеристики бросаются как 4d6 с отбрасыванием худшего кубика, у каждого персонажа свой сигил. Анкету можно скопировать в чат мероприятия.
- **Проверки d20.** Клик по характеристике даёт d20 + модификатор. Так решаются споры между игроками.
- **Доска квестов.** 12 заданий, опыт и ранги.
- **Гримуар.** Команды Claude Code под фэнтезийными названиями.
- **Устав.** Правила игры.

Сайт состоит из одного файла `index.html`, сборка и сервер не нужны. Прогресс игрока хранится в `localStorage` его браузера.

Фанатский проект, не официальное мероприятие Anthropic.
